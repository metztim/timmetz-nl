My-OS is the personal operating system behind my daily work: a private set of scripts, CLI tools, and Claude Code agents that connect Notion, Logseq, email, and calendars into one system. Morning briefs, task management, meeting processing, and always-on monitoring all run through it.

The repo is private (it's wired into my actual life), but pieces of it graduate into public projects: [Sentinel](/projects/sentinel) started here, and many of the workflows on this site come out of it.
