If you’re experiencing issues logging in to the Saent desktop app on Windows, you can download the below update. A few words of caution:

1.  This is not yet an official release as we need more people to try it out to make sure it's stable.
2.  The login problem had to do with an expired SSL authentication issue. To “fix” this problem, we’ve disabled SSL for now. This means your connection to the Saent server is less secure than before. If this concerns you, it’s better not to use Saent until we’ve found a different solution.

You can download the beta update from the below Dropbox link (Windows-only): **\>** [**Saent4WinSetup\_SSL-fix-20180516.zip**](https://www.dropbox.com/s/m90adlzxt3it9s3/Saent4WinSetup_SSL-fix-20180516.zip?dl=0)It would be much appreciated if you can let us know if this fixes the problem; your feedback will help us finalize the release. Also, if you have any questions about the risks of disabling SSL, don't hesitate to reach out to us [on Twitter](http://twitter.com/getsaent).
